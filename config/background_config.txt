# Japanese Vocabulary Trainer — Section-specific background configuration
#
# This file controls the decorative background shown behind the application.
# Configuration is section-specific. A new application section can use a
# background simply by adding a new [section] block; no application-code change
# is required.
#
# Supported sections in the current application:
#   quiz
#   training
#   words
#   backup
#
# [default] is used when a section has no own configuration.
#
# Settings:
# image               = image filename or path. A bare filename is loaded from
#                       backgrounds/. A path containing / is used as written.
# default_hide        = on/off. Initial visibility of the background.
# size                = CSS background-size fallback value, for example cover,
#                       contain, auto, or a CSS length/percentage expression.
# size_portrait       = optional size for normal portrait displays. Falls back to size.
# size_landscape      = optional size for normal landscape displays. Falls back to size.
# size_small          = optional size for small displays. Falls back to the
#                       applicable normal orientation value, then size.
# size_small_portrait = optional size for small portrait displays.
# size_small_landscape= optional size for small landscape displays.
#
# position            = CSS background-position fallback value, for example
#                       center center, right top, or 50% 20%.
# position_portrait   = optional position for normal portrait displays.
#                       Falls back to position.
# position_landscape  = optional position for normal landscape displays.
#                       Falls back to position.
# position_small      = optional position for small displays.
# position_small_portrait = optional position for small portrait displays.
# position_small_landscape= optional position for small landscape displays.
# background_opacity  = 1–100. Opacity of the background image itself.
# surface_opacity    = 1–100. Opacity of translucent application surfaces.
#                       80 means the surface is 80% opaque, so about 20% of the
#                       background can show through it.
#
# Supported background image formats:
#   JPEG (.jpg, .jpeg), PNG (.png), and WebP (.webp).
# The application uses the browser image loader. Unsupported or invalid image
# files are reported through the central configuration-warning system and use
# the configured fallback behavior.
#
# background_opacity and surface_opacity are independent.
# The background is a separate visual layer and does not participate in layout,
# vocabulary, quiz, training, or other application logic.
#
# If the configured image cannot be loaded, the application keeps working and
# falls back to [default] when available, otherwise to the normal application
# background. The existing configuration-warning indicator reports the problem.
#
# Background visibility is controlled only by default_hide in this file.
# There is no runtime hide/show button in the application UI.
# SMALL DISPLAY
# "small" is determined by the responsive viewport breakpoint (max-width: 600px).
# It is not device-model detection and therefore also applies to other small displays.
# Portrait and landscape are evaluated independently.
#
# Position fallback hierarchy:
#   small portrait  -> position_small_portrait -> position_small
#                    -> position_portrait -> position
#   small landscape -> position_small_landscape -> position_small
#                    -> position_landscape -> position
#   normal portrait -> position_portrait -> position
#   normal landscape-> position_landscape -> position
#
# Size follows the same hierarchy independently:
#   small portrait  -> size_small_portrait -> size_small
#                    -> size_portrait -> size
#   small landscape -> size_small_landscape -> size_small
#                    -> size_landscape -> size
#   normal portrait -> size_portrait -> size
#   normal landscape-> size_landscape -> size
#
# Position and size are independent. Defining one does not require defining the other.
# Example:
#   position_small_portrait=100% 0%
#   size_small_portrait=90%
#
# Orientation means the CSS viewport orientation.
