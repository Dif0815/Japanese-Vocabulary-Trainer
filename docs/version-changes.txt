Japanese Vocabulary Trainer — Version Changes

Version 28
----------
- Restructured the repository into dedicated data/, config/, icons/, and docs/ directories.
- Moved vocabulary.csv and data-changes.txt into data/.
- Moved all customization/default and layout files into config/.
- Moved SVG assets into icons/.
- Moved version history into docs/.
- Updated all application file-loading and icon references to the new paths.
- Updated README.txt to document the final repository structure and the new source/configuration separation.
- No vocabulary/data changes in v28.

Version 27.1
------------
- Reduced only the checkmark inside the Words status-filter checkbox; the checkbox square remains at the v27 size.
- Fixed Quiz Ask Type focus after a verb/adjective subtype is selected by touch so focus returns to the main answer field. This allows Enter to continue to Next after an incorrect subtype answer.
- No vocabulary/data changes in v27.1.

Version 27
----------
- Corrected the Words status-filter checkbox styling so the checkbox square is compact, with the existing checkmark size preserved and no heavy black active fill.
- Added a dedicated type-config.txt file for verb/adjective subtype labels and keyboard aliases.
- Kept subtype discovery data-driven: available subtypes still come from vocabulary.csv; type-config.txt only defines presentation and keyboard mappings for known subtypes.
- Removed the previous hardcoded verb/adjective subtype labels and keyboard mappings from application code.
- Added configurable romaji/kana keyboard aliases, including i / い for i-adjectives and n / na / な for na-adjectives.
- Added a subtle grey warning in the Ask Type popup when the current CSV subtype is not defined in type-config.txt. No fallback subtype definition is used; undefined subtypes remain touch-selectable by their raw CSV value.
- Added a subtle general word-type hint below the question in both Quiz and Training. The hint shows only the general word type, not the verb/adjective subtype.
- Updated README.txt to document the current v27 architecture, subtype configuration, keyboard aliases, warning behavior, and question-type hints.
- Added type-config.txt to the application file set.

Version 26
----------
- Refined the Words status controls: the checkbox square is smaller while the checkmark remains visually prominent.
- Removed the separate Mixed-mode status header row and added a per-word Status label so the overall status aligns consistently with JP -> EN and EN -> JP.
- Added keyboard input to the Ask Type popup while preserving direct touch selection. Prefix input highlights a matching subtype and Enter confirms it.
- Made Quiz Ask Type subtype choices data-driven: verb and adjective subtypes are discovered from the CSV instead of being hardcoded.
- New CSV subtype values automatically become available in the type popup and type checking; unknown values use a generic label fallback.
- Updated README documentation to describe the data-driven subtype architecture, keyboard type handling, layout architecture, and backup compatibility with vocabulary changes.

Version 25
----------
- Refined the Words status checkboxes: smaller, less prominent, and no longer rendered as solid-black active controls.
- Replaced the combined Words status-filter default with four independent on/off settings in options-defaults.txt.
- Added a Status header above the overall word-status column in Mixed Words mode so the overall status aligns with JP -> EN and EN -> JP.
- Improved the shared layout engine so empty logical lines do not consume vertical space. Subsequent populated lines are compacted upward.
- Applied empty-row compaction consistently to Last, Training Reveal, and Word Popup layouts.
- Refined README documentation so it describes the current application only.
- Moved version history into this file.
- Moved vocabulary/data change history into data-changes.txt.

Version 24
----------
- Fixed configurable layout handling so empty fields do not create phantom columns or large gaps.
- Added configurable Needs Review recovery with review_recovery_accuracy=80 and review_recovery_min_answers=5.
- Turned the Words status legend into multi-select filters.
- Made Partially learned Mixed-mode-only and added the overall status column per word.
- Kept the Words legend order as Learned -> Not learned -> Needs review -> Partially learned.

Version 23
----------
- Centralized answer normalization so parenthetical qualifiers are removed before alternative answers are split.
- Applied the same normalization to English -> Japanese checks.
- Added Enter handling for Quiz and Training.

Version 22
----------
- Added the Words status legend.
- Made Needs Review visible only when active while preserving alignment.

Version 21
----------
- Fixed the Quiz Skip button regression.
- Kept Ask Type behavior simple: when OFF, translation determines correctness; when ON, translation and type must both be correct.
- Fixed repetition spacing so min_different_words_between_repetitions=5 means five different words between repetitions.
- Added maximum-possible fallback when the filtered pool is too small to satisfy the requested spacing.
- Cleaned up learning-data storage/version bookkeeping.
